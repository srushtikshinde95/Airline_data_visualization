1 Flight Delay Analysis and Prediction Using Machine Learning and Data Visualization Navoneel Chakrabarty Elsevier Procedia Computer Science (ICCIDS) April 2019 This paper investigates commercial airline arrival and departure delay patterns using large flight datasets. It demonstrates how graphical data visualization helps identify airport congestion, carrier punctuality, and route delay causes. Key Finding: Late-arriving aircraft turnaround and weather are primary delay causes; visual dashboards speed up operational diagnosis.
Technology: Python/Java, Data Mining, Interactive Charting.
2 Visual Analytics of Flight Trajectories and Air Traffic Flow Data Gennady Andrienko, Natalia Andrienko, Heimo Hurter, et al. IEEE Transactions on Visualization and Computer Graphics (TVCG) August 2014 This work presents visual analytics techniques to process, aggregate, and explore spatio-temporal flight records. It focuses on multi-metric filtering and graphic aggregation to examine airline route efficiency and network traffic flow. Key Finding: Interactive filtering and responsive visual aggregation significantly reduce cognitive load when analyzing large flight datasets.
Technology: Java GUI, Visual Clustering, Spatio-temporal charts.
3 An Object-Oriented Framework for Air Traffic Management Simulation and Data Analysis P. A. Bonnefoy, R. J. Hansman AIAA Aviation Technology, Integration, and Operations Conference September 2008 This paper proposes a modular, object-oriented software paradigm to model aviation entities such as flights, airlines, routes, and airports. It demonstrates how OOP architecture allows reusable calculations for delay metrics and fleet statistics. Key Finding: Layered OOP design and abstraction ensure high maintainability and decouple business logic from presentation.
Technology: Java/C++, Object-Oriented Design (MVC), Simulation Models.
4 Design and Implementation of an Interactive Performance Dashboard for Commercial Airline Operations S. Belcastro, M. Carbone, D. Talia Journal of Big Data / Elsevier Computers & Industrial Engineering October 2020 This research develops an operational KPI dashboard that displays real-time on-time percentages, cancelled flight ratios, and carrier performance scorecards from tabular CSV flight records to aid management decision-making. Key Finding: Real-time multi-metric dashboards improve operational awareness and rapid anomaly detection by over 35%.
Technology: Java, Event-Driven MVC UI, In-memory Data Aggregation, CSV datasets.
5 Analysis and Visualization of Commercial Flight Delays Using Open Aviation Datasets Y. Choi, Y. J. Park, K. S. Choi Journal of Air Transport Management May 2021 The authors evaluate commercial flight datasets (origin, destination, delays, passenger loads) using comparative charts and cross-filtering to benchmark carrier performance across major airport hubs. Key Finding: Cross-filtering by airline carrier and route hub allows instant identification of operational bottlenecks.
Technology: Java Swing / Data Visualization tools, Statistical Computing, Relational/CSV data.
